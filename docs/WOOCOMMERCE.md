# WooCommerce

## Modèle de données

Utiliser produits simples/variables, catégories, attributs, stock natif, classes d’expédition, taxes, coupons et commandes. Les badges viennent uniquement de l’état réel du produit.

AYRU Core ajoute cinq champs au panneau général produit : fabricant, responsable UE, référence, âge/avertissements et informations de sécurité. Ils ne s’affichent sur la fiche que lorsqu’ils sont renseignés.

## Paiement

Installer uniquement l’extension officielle ou maintenue du prestataire choisi. Les champs doivent être hébergés/tokenisés par la passerelle. AYRU ne stocke aucune donnée de carte.

## Plugins requis

| Plugin | Justification |
|---|---|
| WooCommerce | Catalogue, stock, panier, commande, client, taxes et emails |
| AYRU Core | Fonctions métier spécifiques livrées avec le projet |
| Passerelle à choisir | Paiement tokenisé ; non installée sans décision commerciale |

Un plugin SEO ou cache peut être ajouté seulement après choix d’hébergement et audit de compatibilité.
